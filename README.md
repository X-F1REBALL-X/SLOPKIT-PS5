## Setup

1. Open the live link on the PS5 browser — the jailbreak starts automatically.
2. Wait for **Jailbreak completed successfully**.
3. Payload Manager and **PS5-WebKit-Autoloader** installer load automatically.
4. Leave the installer open until the homescreen shortcut is ready.
5. **Reboot once.**
6. Open **PS5-WebKit-Autoloader v1** from the homescreen.
